# 洛玖

洛玖是一个本地运行的群聊成员。她有多用户、多群聊、持久记忆、延迟教学和可替换的大脑。默认只绑定本机，数据在 `data/luojiu.sqlite3`。

## 运行

在当前目录打开 Anaconda Prompt：

```powershell
conda env create -f environment.yml
conda activate luojiu
python -m luojiu --port 8765
```

也可以直接使用已有的 Conda Python：

```powershell
python -m luojiu
```

打开 `http://127.0.0.1:8765/`。第一次需要注册一个用户并创建群；在群设置里复制邀请码给其他用户。教学后台是 `http://127.0.0.1:8765/studio.html`。

## 她怎样成长

当下消息先被保存为经历。洛玖根据消息的新鲜度、群聊节奏、近期发言时间和自己的能量/好奇度决定是否加入；她可以保持沉默。群友之间的问答会先成为待确认候选，不能自动污染共享大脑。

主人在群聊回答下点击反馈，或在教学后台逐条确认。确认发生在事后，教学会改变大脑的局部节点、兴奋/抑制状态和稀疏结构连接。后台时钟每 20 秒让时间继续流动，进行低频复习和等待；洛玖不会把自己的生成文本当成训练样本。

第一版 `SMGrNN` 位于 `luojiu/brain.py`，实现了：

- 独立随机间隔的局部脉冲事件，没有全局时间步或批次矩阵；
- 每个节点独立的膜电位、兴奋、抑制、阈值和脉冲率；局部反馈把兴奋/抑制维持在动态范围；
- 教学导致节点生长、原型移动、邻近节点合并，长期未使用节点衰减；
- 结构连接保存在 `synapses`，共同脉冲的功能相关保存在 `functional`，两者彼此独立。

外壳只使用 `luojiu/brain.py` 的 `Brain` 接口：`perceive`、`respond`、`teach`、`feedback`、`state`。以后替换为别的动态网络，只需实现这个接口并更换工厂；SQLite 消息、用户、群、历史教学和页面不用改。

## 备份与隐私

关闭服务后复制 `data/luojiu.sqlite3` 即可备份。用户密码使用 PBKDF2 保存，服务默认只监听 `127.0.0.1`。如果要让局域网访问，明确指定 `--host 0.0.0.0`，并在外层加认证和 HTTPS。

当前版本不下载模型、不访问网络、不需要第三方 Python 包。
